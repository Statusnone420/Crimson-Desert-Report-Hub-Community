# Contributing

Corrections, clear reader guides, accessibility reports, and useful suggestions are welcome.

## Choose the right place

- Use [Issues](https://github.com/Statusnone420/Crimson-Desert-Report-Hub-Community/issues/new/choose) for a website bug, correction, or specific feature request. Check existing issues first.
- Use [Discussions](https://github.com/Statusnone420/Crimson-Desert-Report-Hub-Community/discussions) for questions, ideas, and conversation about the Hub.
- Use the website's [Issue Board](https://crimsonreporthub.com/issues) for anonymous check-ins about existing game issues. The Hub cannot provide game or account support; contact [Pearl Abyss](https://support.pearlabyss.com/) for that.

Include the affected public page, what happened, and what you expected. For corrections, include a public source when available. Posts and attachments are public. Remove personal information and private account details before posting.

## Improve the documentation

Open a pull request with the smallest useful change. Use plain language, keep links working, and preserve the distinction between official statements, player check-ins, and source context.

Reader guides live in `wiki/`. The GitHub Wiki mirrors those files; I publish accepted guide changes there. This repository contains community documentation and issue forms, so application builds and code tests are not required.

Keep discussion respectful and focused on the issue. Disagreement is welcome; harassment and spam are not.
