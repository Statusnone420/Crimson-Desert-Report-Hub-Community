# Crimson Desert Report Hub

Crimson Desert news, original reports, official updates, and the player record — with sources kept in view.

[Read the newspaper](https://crimsonreporthub.com/) · [Reader wiki](https://github.com/Statusnone420/Crimson-Desert-Report-Hub-Community/wiki) · [Report a site problem](https://github.com/Statusnone420/Crimson-Desert-Report-Hub-Community/issues/new/choose) · [Discussions](https://github.com/Statusnone420/Crimson-Desert-Report-Hub-Community/discussions)

I run Crimson Desert Report Hub as an independent fan newspaper. This is its public community space: reader guides, corrections, website issues, ideas, and discussion. Application development lives in a separate repository.

## Explore the Hub

| Visit | What you will find |
| --- | --- |
| [News](https://crimsonreporthub.com/news) | Original reporting and selected coverage, with sources and publication dates. |
| [Patch record](https://crimsonreporthub.com/patches) | Official patch rundowns, source links, and the patch archive. |
| [Issue Board](https://crimsonreporthub.com/issues) | Anonymous check-ins about game issues on the current patch. |
| [Watch](https://crimsonreporthub.com/watch) | Selected creator videos. |
| [Observatory](https://crimsonreporthub.com/observatory) | Review trends, audience activity, and source radar. |

Follow original Hub articles and official patch rundowns through [Atom](https://crimsonreporthub.com/feed.xml) or [RSS](https://crimsonreporthub.com/rss.xml). External coverage and player submissions stay out of these feeds.

## Take part

- **Wrong detail, missing credit, or broken link:** [send a correction](https://github.com/Statusnone420/Crimson-Desert-Report-Hub-Community/issues/new?template=correction.yml).
- **Something broken on the website:** [report a site bug](https://github.com/Statusnone420/Crimson-Desert-Report-Hub-Community/issues/new?template=bug_report.yml).
- **Ideas and questions:** join [Discussions](https://github.com/Statusnone420/Crimson-Desert-Report-Hub-Community/discussions) or [suggest a feature](https://github.com/Statusnone420/Crimson-Desert-Report-Hub-Community/issues/new?template=feature_request.yml).
- **A game issue happening to you:** use the website's [Issue Board](https://crimsonreporthub.com/issues). Game and account support belongs with [Pearl Abyss](https://support.pearlabyss.com/).

GitHub issues and discussions are public and require a GitHub account. Keep personal information, account details, private messages, and personal logs out of posts and screenshots. Anonymous website check-ins do not require a GitHub account.
