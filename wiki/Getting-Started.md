# Getting started

Start at [crimsonreporthub.com](https://crimsonreporthub.com/) for the current edition. The [News page](https://crimsonreporthub.com/news) collects original Hub reports and selected external coverage. [Watch](https://crimsonreporthub.com/watch) collects selected creator videos.

## Read the patch record

The [patch record](https://crimsonreporthub.com/patches) brings together retained official patch notes, automatic rundowns, and links to Pearl Abyss. Use the archive to revisit an earlier patch. A developer's fix claim is not proof that a problem is gone for every player.

## Add a check-in

Open an issue on the [Issue Board](https://crimsonreporthub.com/issues), choose your platform, and select **Happening to me** or **Not happening for me**. An eligible official fix offers **Fixed for me** or **Still happening**.

Check-ins are anonymous and require an anti-abuse check, not a user account. Each exact patch, including a hotfix, starts a fresh tally. Changing your answer replaces the earlier response for the same issue and patch. Shared networks can share a response, so these totals are not a count of unique players.

The website no longer accepts free-form written game reports. Approved historical excerpts may remain in the record.

## Explore the context

The [Observatory](https://crimsonreporthub.com/observatory) shows review trends, audience activity, and source radar when available. These are context, not proof of a game issue or a fix.

For website problems or corrections, see [Reporting a problem](https://github.com/Statusnone420/Crimson-Desert-Report-Hub-Community/wiki/Reporting-a-Problem).
