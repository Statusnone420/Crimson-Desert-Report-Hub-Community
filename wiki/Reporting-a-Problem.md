# Reporting a problem

| Problem | Where to go |
| --- | --- |
| Incorrect detail, missing credit, or broken link | [Correction form](https://github.com/Statusnone420/Crimson-Desert-Report-Hub-Community/issues/new?template=correction.yml) |
| Website layout, navigation, or other site bug | [Website bug form](https://github.com/Statusnone420/Crimson-Desert-Report-Hub-Community/issues/new?template=bug_report.yml) |
| Specific website improvement | [Feature request](https://github.com/Statusnone420/Crimson-Desert-Report-Hub-Community/issues/new?template=feature_request.yml) |
| Question or idea to discuss | [Discussions](https://github.com/Statusnone420/Crimson-Desert-Report-Hub-Community/discussions) |
| Your experience with an existing game issue | [Anonymous Issue Board check-in](https://crimsonreporthub.com/issues) |
| Game or account support | [Pearl Abyss support](https://support.pearlabyss.com/) |

For a website issue, include the affected page, what happened, and what you expected. For a factual correction, add a public supporting source when possible.

GitHub posts are public and require an account. Do not post passwords, account details, private messages, or personal logs. The Hub is an independent fan project and cannot resolve game accounts or provide official support.
